## Channel3 (live API, key in `.env.local` as `CHANNEL3_API_KEY`)

Source: the installed skill `.agents/skills/channel3-api/` (SKILL.md + references/api-reference.md, read in full) and live calls on 2026-11-05.

- **Client:** official SDK `@channel3/sdk` (v4): `import { Channel3 } from '@channel3/sdk'`, `new Channel3({ apiKey: process.env.CHANNEL3_API_KEY })`. Requests use snake_case fields; paginated calls return a `Page` with `.data`.
- **Search:** `client.products.search({ query, filters: { website_ids: [...domains], price: { max_price } }, limit })` → `page.data: Product[]`. Raw HTTP response: `{ products, next_page_token }`.
- **`website_ids` accepts plain domains** (e.g. `"bestbuy.com"`). Verified live: filtering by a domain returns only offers from that domain.
- **Product fields used by Tether:** `id`, `title`, `category.slug` (e.g. `over-ear-headphones`, `print-books`, `hoodies-3`, `sneakers`), `offers[]` with `domain`, `price.price` (float dollars, post-discount), `price.currency`, `availability` (`InStock`/`OutOfStock`), `url` (**affiliate-tracked — never render clickable**). Also present but **never shown to the teen:** `ratings`.
- **A product can have offers from several shops** (live: one Sony headphone had `cdw.com` $48.99 and `macys.com` $58.00). Tether picks the offer whose `domain` is in the allowed list.
- **Lookup (pasted link):** `client.products.lookup({ url })` → `{ product }`; 2–10 s uncached; `422` non-product page, `504` timeout.
- **Refresh at settle time:** `client.products.retrieve({ product_id, website_ids? })` — **free**, current prices. Use this (not lookup) for the "did the price change?" re-check.
- **Shop picker:** `client.websites.search({ query })` → `Website { id, url, best_commission_rate }` — never display the commission rate.
- **Attribution:** never send `x-user-id` (it tags affiliate links).
- **Cost:** search/lookup 1 credit; products.retrieve free; websites/brands/categories free.

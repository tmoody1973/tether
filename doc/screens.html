Two apps, one mandate

Ten screens across the two surfaces. The teen app is built to make one number obvious and every refusal explainable; the guardian app is deliberately sober, and the moment of granting authority is the plainest screen in the product. All copy matches the specification in HOW-IT-WORKS.md, so these can be lifted straight into the demo video.

Teen palette

Guardian palette

Decisions

  • Refusal is amber, never red. A blocked purchase is information, not punishment.
  • No AI in the consent path. The grant reads like a contract in a serif face.
  • One number per screen. The teen app shows what's left, oversized.
  • Tabular figures everywhere money appears, so digits don't jitter.
  • The parent sees signals, not a feed. "Nothing needs you today."

Type

  • UI: Inter / system sans — 800 for money, 650–750 for headings
  • Body: 13–15px, 1.45–1.6 line height
  • Contract clause: Georgia serif, 1.62 line height
  • Money: 60px hero, tabular numerals, −0.035em tracking
